1. Who we are

AutoShorts AI is an independent personal project based in Vietnam. It is not a registered company. For the purposes of applicable data-protection law, the Project’s maintainer acts as the controller of the limited personal data described below.

Contact for privacy questions, access requests, or deletion requests: nduy28092008@gmail.com.

2. Scope of this policy

This policy explains how data is handled when you use the AutoShorts AI software and when you visit these legal pages. It does not govern TikTok, Shopee, Google, Microsoft, GitHub, or any other third-party service. Those services publish their own privacy policies.

AutoShorts AI is designed primarily as local software. We do not operate a central server that stores your products, videos, or TikTok tokens. The optional TikTok connection is handled by the software on your own computer.

3. What data is processed

3.1 Data stored locally by the application

  • Product data: Shopee links, product names, prices you enter, descriptions, images, attributes, and metadata source information.
  • Creative data: generated scripts, captions, hashtags, voice-over audio, subtitles, thumbnails, MP4 files, and publishing packages.
  • Operational data: job history, video status, review decisions, settings, usage counters, and application logs.
  • Local database: the application’s SQLite database and working files.

This data is stored in the application folder on your device (for example, the data/, output/, and logging directories), unless you choose to move or back it up elsewhere.

3.2 TikTok account data (only if you connect TikTok)

If you choose to connect a TikTok account, TikTok’s OAuth flow returns an access token, a refresh token, and information about the permissions granted. The Project may also request basic profile information such as your TikTok display name, avatar URL, and open ID, if the granted scopes allow it.

These values are stored in a local token file (by default secrets/tiktok_token.json). The application does not ask for your TikTok password and does not use TikTok login cookies or automated browser sessions.

3.3 Data sent to TikTok when you publish

When you explicitly confirm publishing or sending a draft, the Project sends the selected video file, caption, hashtags, privacy selection, commercial-content settings, AI-generated-content flag, and related API parameters to TikTok. TikTok also receives technical information such as your IP address and request metadata as part of that API call. TikTok processes this data under its own privacy policy.

  • to provide the features you request: product lookup, script generation, voice-over, video rendering, review, and storage of your projects;
  • to connect to TikTok and publish or draft content only after your explicit confirmation;
  • to maintain security, prevent duplicate uploads, diagnose errors, and improve reliability;
  • to respond to your support, privacy, or deletion requests; and
  • to comply with applicable legal obligations.

Where a legal basis is required, processing is generally based on performing the service you request, your consent (for optional connections such as TikTok), and legitimate interests in operating and securing a local personal project.

5. Where data is stored

Product data, videos, logs, settings, and TikTok tokens are stored on your own device in the application folder. We do not maintain a copy on a central server.

The TikTok token file is created with restricted file permissions where the operating system supports it. The application does not encrypt the token file itself beyond the protection provided by your operating system and device. You are responsible for securing your computer, user account, backups, and any cloud-sync folder in which the project is stored.

These legal pages are static files hosted on GitHub Pages. They do not receive or store your application data.

6. When data is shared

We do not sell your personal data, and we do not use it for advertising or profiling. Data is shared only:

  • with TikTok, when you choose to connect an account or confirm a post/draft;
  • with Shopee, when you ask the Project to retrieve a public product page;
  • with Google Gemini or Microsoft Edge TTS when you enable those features;
  • with GitHub when you visit these pages or use GitHub-based deployment; and
  • with authorities or other parties when required by law, or to protect rights and safety.

Because the application is local, you control the main copy of your data. If you share your project folder, database, logs, videos, or token file with someone else, you are sharing that data yourself.

7. Cookies and website data

These legal pages do not set cookies, use analytics, or load advertising or tracking scripts. They use only locally hosted CSS and system fonts. GitHub, as the hosting provider, may process standard request logs under its own privacy policy.

The local dashboard may use browser local storage for preferences such as the selected display theme. It is not used for advertising or cross-site tracking.

8. Retention, disconnection, and deletion

8.1 How long data is kept

Local data remains on your device until you delete it or remove the application. TikTok tokens remain until you disconnect, delete the token file, or revoke access. We do not keep a separate server-side copy to delete.

8.2 Disconnect TikTok

  1. Open the AutoShorts AI dashboard and go to the TikTok page.
  2. Select Disconnect. The application attempts to revoke the OAuth grant with TikTok and deletes the local token file.
  3. You can also review and revoke the app’s access in your TikTok account’s security or connected-apps settings.

Revoking access does not delete posts or drafts that already exist on TikTok. Manage those inside TikTok.

8.3 Delete local data

To delete the Project’s local data, close the application and delete the relevant project folders and files, including the local database (data/), generated media (output/), logs, and the token file (secrets/tiktok_token.json). If you use backups or cloud sync, delete those copies as well.

8.4 Request deletion

If you believe the Project holds personal data about you and you cannot remove it yourself, email nduy28092008@gmail.com with enough detail for us to identify the data. We will assess the request and respond within a reasonable period (normally within 30 days). We may need to verify that you are the account holder. Because most data is local, we may ask you to delete local files and confirm the action rather than being able to delete them remotely.

9. Security and limitations

We take practical measures appropriate for a local personal project: OAuth is handled in the backend, client secrets and tokens are not shown in the browser, the token file has restricted permissions where supported, tokens are not written to application logs, and the public website contains only static legal pages.

However, no method of storage or transmission is perfectly secure, and the Project does not provide enterprise-grade security guarantees. In particular:

  • the application does not encrypt your local database, videos, or token file itself;
  • anyone with access to your computer or synced project folder may be able to read your data or token;
  • third-party providers process data under their own security practices; and
  • you are responsible for keeping your device, operating system, API keys, and accounts secure.

If you believe a token or account has been compromised, disconnect TikTok, revoke access in TikTok, and rotate any API keys you use.
